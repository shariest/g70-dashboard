# G70 display languages

G70 Dashboard and G70 My Apps each support Korean, English and **System**. System selects Korean for a Korean system locale and English otherwise. Android displays launcher labels using its own locale resources.

- In **G70 Dashboard**, tap **KO** or **EN** beside the clock and choose a language.
- In **G70 My Apps**, open **Language**, choose an option and save. Enabled shortcuts refresh their labels.
- Each app saves its own selection. Units, telemetry decoding, layouts, media titles and labels supplied by other apps are independent of this setting.

## 한국어
