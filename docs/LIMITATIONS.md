# G70 대시보드의 지원 범위

대상은 국내 2019년형 G70 표준형 5세대 내비게이션입니다. G70에서 사용할 수 있는 OEM 매니저, 권한, 수신 데이터는 Probe로 확인할 단계입니다. 계기판의 `automotive` 공유 라이브러리 요구사항과 API 17 대상으로 빌드한다는 사실만으로 설치 가능 여부를 판단할 수 없습니다. [호환성·실차 검증](STATUS.md#한국어)

| 소스에 구현된 항목 | G70에서 확인할 점 |
| --- | --- |
| RPM·속도·기어·온도 | OEM 콜백 유무, 단위, 오프셋. 기존 수동 기어 표시는 자동변속기 상태를 검증한 결과가 아닙니다. |
| 네 바퀴 TPMS | 바퀴별 위치와 압력값. 화면 단위는 psi입니다. |
| 출력·토크·부스트 | 일부는 수신값으로 계산합니다. 계산식의 G70 적용성은 미확인입니다. |
| TCS·ESC·ABS·e-LSD·배기온 | 원본 차종에서도 실제 개입·의미를 전부 확인하지 못했습니다. |
| HSCAN | 대시보드의 추가 수신 경로는 원본 펌웨어 식별값으로 제한됩니다. G70 포맷과 함수 코드는 별도 조사 대상입니다. |
| 바로가기·미디어·Bluetooth | 오버레이, 알림창, 미디어 정보와 관련 권한은 헤드유닛에 따라 다릅니다. |
| 계기판 표시 제한 | 후방 카메라·차량 상태 콜백이 G70에서 전달되는지 확인이 필요합니다. |

계기판은 마지막 수신 뒤 60초가 지난 값을 대시로 표시합니다. PC 미리보기에는 합성값을 사용합니다. 앱에서 무선 CarPlay, OTA 또는 자동 업데이트를 제공하지 않습니다. [퍼포먼스 화면](PERFORMANCE.md) · [조사 과정](RESEARCH_ko.md)
