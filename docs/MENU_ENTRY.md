# G70 factory-menu entry

G70 My Apps exposes the Android launcher activity `com.github.shariest.g70.hub/.HubActivity`. A launcher that lists installed apps can open it. Inside My Apps, an edge button and a notification are available as opt-in shortcuts. Visibility on the G70 factory HOME screen requires a vehicle check. [My Apps](MY_APPS.md) · [Quick entry](QUICK_ENTRY.md)

There is no G70 factory-menu installation profile. The original vehicle's menu APK and ODEX identities are archived and are outside the active installer. [Compatibility](STATUS.md) · [Release history](RELEASE.md)
