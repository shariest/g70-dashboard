# G70 내 앱

[English](MY_APPS.md) · [설치 상태](INSTALL.md)

G70 내 앱(`com.github.shariest.g70.hub`)은 순정 내비에서 계기판, 설치한 앱, 기기가 제공하는 설정 화면을 열기 위한 실행기입니다. 아래 내용은 현재 소스의 동작입니다.

| 화면 항목 | 동작 |
| --- | --- |
| G70 계기판 | 별도 앱 `com.github.shariest.g70.dashboard/.DashboardActivity`를 엽니다. |
| 실행 바로가기 | 가장자리 버튼과 알림, 알림만, 사용 안 함 중 하나를 저장합니다. 기본값은 사용 안 함입니다. |
| 목록 편집 | 표시할 앱을 고릅니다. 선택은 이 실행기에 저장됩니다. |
| 언어 | 시스템 언어·한국어·영어 중 하나를 고릅니다. |
| 안드로이드 기본앱·엔지니어링 모드 | 설치되어 있고 외부 실행을 허용하는 설정 화면을 엽니다. |
| 블루투스 연결 설정 | Android에서 제공하는 Bluetooth 검색과 페어링을 사용합니다. |
| USB 디버깅·강제 재시작 | 헤드유닛의 OEM 기능과 권한에 의존합니다. 재시작 요청에는 확인창이 있습니다. |
| 연결 점검 | 네트워크 상태와 시험용 핫스팟을 확인합니다. 무선 CarPlay는 구현되어 있지 않습니다. |

G70 계기판과 내 앱은 각자 언어 설정을 저장합니다. 첫 화면에서 계기판을 열 수 있는지와 HOME으로 돌아간 뒤 내 앱을 다시 열 수 있는지는 따로 확인합니다. [언어 설정](LANGUAGES.md#한국어) · [바로가기](QUICK_ENTRY_ko.md)
