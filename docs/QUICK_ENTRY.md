# G70 My Apps shortcuts

[한국어](QUICK_ENTRY_ko.md) · [G70 installation status](INSTALL_EN.md)

The source launcher provides optional shortcuts for returning to G70 My Apps from another screen. The default is **Off**. On a test installation, open **Quick entry**, choose a mode and tap **Save**.

| Mode | Expected behavior |
| --- | --- |
| Floating + notification | A draggable edge button opens My Apps. The notification also opens it. If the overlay is denied, the service keeps the notification when possible. |
| Notification only | An ongoing notification opens My Apps. Access depends on the factory notification UI. |
| Off | Removes shortcuts and disables their restoration. |

While parked, return to HOME, open the shortcut, then tap **G70 Dashboard**. If the edge button is missing, check the saved mode and try the notification. The service hides the overlay while the screen is off or locked. After a force-stop, open My Apps again before testing restoration.

When shortcuts are enabled, the receiver requests service restoration after boot. Visibility after a full G70 shutdown and restart still requires a separate vehicle test. [Verification status](STATUS.md)
