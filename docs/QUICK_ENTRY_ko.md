# G70 내 앱 바로가기

[English](QUICK_ENTRY.md) · [G70 설치 상태](INSTALL.md)

내 앱을 다른 화면에서 다시 열 때 쓰는 기능입니다. 소스 빌드의 기본값은 **사용 안 함**입니다. 시험 설치본에서 **실행 바로가기**를 열어 방식을 고르고 **저장**을 누릅니다.

| 방식 | 예상 동작 |
| --- | --- |
| 가장자리 버튼 + 알림 | 작은 버튼을 끌어 위치를 정하고 눌러 내 앱을 엽니다. 오버레이가 거부되면 가능한 경우 알림이 남습니다. |
| 알림만 | 알림에서 내 앱을 엽니다. 순정 화면에서 알림창에 접근할 수 있어야 합니다. |
| 사용 안 함 | 버튼과 알림을 내리고 부팅 뒤 복원을 끕니다. |

정차 상태에서 HOME으로 돌아가 바로가기 → 내 앱 → **G70 계기판** 순서로 열어 봅니다. 버튼이 안 보이면 저장된 방식을 확인하고 알림을 시도합니다. 화면 꺼짐·잠금 상태에서는 버튼이 숨겨집니다. 강제 종료했다면 내 앱을 직접 다시 연 뒤 확인합니다.

바로가기를 켜 두면 부팅 방송을 받았을 때 서비스 복원을 요청합니다. G70의 완전 전원 종료·재시동 뒤에도 화면에서 접근할 수 있는지는 별도의 실차 확인 항목입니다. [확인 범위](STATUS.md#한국어)
