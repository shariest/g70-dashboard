# G70 status bar and fullscreen media research

The upstream project explored showing artwork and track progress in the OEM status bar and a compact overlay over navigation. Those experiments depended on exact SystemUI inputs, screen dimensions, OEM events and a separate media publisher. There is no G70 build or in-car verification of either integration here.

The G70 dashboard's own media view uses the artwork and metadata available to the app. Touch behavior, rear-camera priority and screen-off behavior of any future system-level overlay would need independent checks on the target head unit.
